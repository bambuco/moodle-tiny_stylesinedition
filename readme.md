# Tiny plugin Styles in edition

A tool designed to easily add styles to the HTML editor.

Package tested in: moodle 4.5+

## QUICK INSTALL
Download zip package, extract the stylesinedition folder and upload this folder into lib/editor/tiny/plugins/.
